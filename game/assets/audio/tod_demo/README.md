# 시간대 섞기 시험 줄기 (사운드 세션, 2026-10-23)

게임 곡이 아니다. 사운드 세션이 줄기 섞기 방식과 제작 도구를 확인하려고 만든 소리로, 사용자 컴퓨터 `멀티 세션용 공유 폴더\사운드\1023 시간대 섞기 시험\`에서 그대로 옮겼다. 곡 방향이 정해지면 사운드 세션이 진짜 곡을 같은 형식으로 다시 만든다(`04_사운드 계획.md`).

- D장조, 72BPM, 4/4, 16마디 = 53.333초, 44.1kHz 스테레오 Ogg Vorbis q4. 다섯 줄기(`bed` 바탕, `dawn` 새벽, `day` 낮, `evening` 해 질 녘, `night` 밤)는 샘플 수가 같고 파일 끝이 곧 루프 지점이다. 가져오기 설정은 `loop=true`, `loop_offset=0`, `bpm=72`, `beat_count=64`, `bar_beats=4`.
- 출처: 사운드 세션이 작업 공간 도구(`nwaudio`)로 악보를 써서 렌더링했다. 악기 샘플은 VCSL과 VSCO 2 CE(둘 다 CC0 1.0). 라이선스 기록은 `04_사운드 계획.md` '라이선스 기록'.
- 게임에서는 `scripts/audio/park_music.gd`가 다섯 줄기를 함께 돌리며 배경 색표와 같은 시간대 무게로 섞는다.
