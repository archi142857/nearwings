# 새바라기(NearWings) 코드

Godot 4.7.2 프로젝트다. 계획과 결정은 claude.ai 프로젝트 문서(`00_README.md`, `01_결정 기록.md`, `03_개발 계획.md`)를 따른다. 코드 세션은 시작할 때 그 문서들과 이 파일을 읽는다.

이 폴더는 사용자 컴퓨터의 `D:\프로젝트 폴더\코딩\NearWings\nearwings\`다(2026-10-22부터). 바뀐 파일을 보내는 법(`nearwings-updateNN.zip`), 시험판과 화면 캡처를 두는 곳은 `..\멀티 세션용 공유 폴더\README.md`에 있다.

지금 단계: **0단계 M5까지** (도시 하천 공원, 화면 비율에 맞춰 고르는 배경 세 벌, 시간대에 따라 바뀌는 배경(새벽·낮·저녁·밤), 새 10종이 한 화면에 0~2마리씩 날아와 앉고 떠남, 뷰파인더와 셔터, 도감 10칸, 기기 저장, 시험용 설정). 남은 것은 M6 재미 시험(기기에서 직접 해 보기).

## 폴더

| 위치 | 내용 |
|---|---|
| `game/` | Godot 프로젝트. 편집기에서 `game/project.godot`를 연다 |
| `game/scripts/` | `main.gd` 장면과 입력, `app.gd` 자동 로드(실행 인자·설정·방향), `core/` 배경 벌 고르기·배율, 시간대, 새가 오는 규칙, 종·횃대·도감 기록, `birds/` 새와 스포너, `ui/` 뷰파인더·셔터·도감·시험용 설정, `selftest.gd` 입력 흉내 자체 시험 |
| `game/shaders/` | `bg_mix` 배경(낮·저녁 섞기), `sharp_sprite` 칸 경계 섞기 |
| `game/assets/birds/` | 새 그림, 1칸 = 1화소. `<종ID>.png`, `_fly1/_fly2`, `_swim` |
| `game/assets/habitats/<서식지>/` | `palettes.json` 색표. 세 벌 `portrait/`(세로형 240×480)·`square/`(정사각형 480×480)·`landscape/`(가로형 480×300)마다 `index.png` 칸마다 색 번호, `baked_*.png` 구운 그림, `perches.json` 횃대 |
| `game/data/species.json` | 0단계 10종 |
| `game/tests/` | 단위 시험 |
| `tools/` | 작업 공간 준비, 검사, APK, 그림 가져오기 |
| `art/habitats/<서식지>/` | 디자인 캔버스에서 뽑은 480×480 임시 월드와 횃대. 세 벌이 오기 전까지 여기서 잘라 쓴다 (게임에는 안 들어간다) |
| `build/` | 만든 APK와 화면 캡처 (보관하지 않는다. 남길 것은 `..\시험판\`, `..\멀티 세션용 공유 폴더\화면 캡처\`에 둔다) |

## 명령 (코드 세션 작업 공간, 리눅스)

- `tools/setup_workspace.sh`: Godot, 안드로이드 템플릿(필요한 파일만), apksigner, 편집기 설정을 준비한다.
- `tools/check.sh`: 단위 시험, 기기마다 앉을 자리 검사, 자체 시험(가상 화면에서 셔터·배경 벌·뷰파인더·도감·뒤로 가기를 흉내, 세 벌을 다 거침), 기기 9종 화면과 도감 화면 캡처(`build/shots/sheet.png`), 배경·새 색 확인.
- `tools/build_apk.sh`: 디버그 APK를 만든다(`build/nearwings-<버전>-<번호>.apk`). 같은 서명 키라 이전 시험판 위에 덮어 깔린다.
- `python3 tools/bake_palettes.py`: 색표(`palettes.json`)나 `index.png`를 고친 뒤 벌마다 구운 배경을 다시 만든다.
- `python3 tools/perch_check.py`: 여러 기기 화면(18가지)마다 고른 벌에서 10종이 모두 앉을 자리가 있는지 보고, 벌마다 늘 보이는 '새 놓을 곳'(안전 영역)을 알려 준다. 기기마다 새 오는 확률이 같으려면 통과해야 한다.
- `python3 tools/temp_sets.py`: `art/`의 임시 월드에서 세 벌을 다시 잘라 만든다(디자인 세션의 세 벌이 오기 전까지).
- `python3 tools/time_palettes.py`: 낮 색표에서 임시 새벽·밤 색표를 만든다(디자인 세션의 시간대 색표가 오기 전까지). 이어서 `bake_palettes.py`.
- `python3 tools/canvas_import.py <캔버스 PNG 폴더>`: 디자인 캔버스 시안에서 임시 그림(새, 월드)을 다시 뽑는다.

Gradle 빌드(안드로이드 플러그인, 위젯)는 이 작업 공간에서 Google·Gradle 저장소가 막혀 있어 안 된다. 필요해지면 클라우드 빌드나 사용자 컴퓨터에서 빌드한다.

새 코드 세션은 사용자 컴퓨터의 이 폴더를 `.git/`과 `game/.godot/`만 빼고 작업 공간으로 옮겨 온 뒤 `tools/setup_workspace.sh`, `tools/check.sh` 순서로 돌리고 이어 간다. 컴퓨터에 연결되지 않은 세션이면 사용자에게 이 폴더를 zip으로 받는다.

## 내 컴퓨터에서 열기

Godot 4.7.2(표준판)를 받아 `game/project.godot`를 열고 F5로 실행한다. 폰 화면처럼 보려면 실행 인자에 `-- --density=2.625`를 주고 창을 세로로 길게 한다.

단위 시험만 돌리려면 cmd에서 Godot 압축을 푼 폴더의 `_console.exe`를 쓴다(처음 한 번은 `--import`가 필요하다).

```
cd /d "D:\프로젝트 폴더\코딩\NearWings\nearwings"
"<Godot 폴더>\Godot_v4.7.2-stable_win64_console.exe" --headless --path game --import
"<Godot 폴더>\Godot_v4.7.2-stable_win64_console.exe" --headless --path game -s res://tests/run_tests.gd
```

실행 인자(`--` 뒤): `--density=2.625` `--seed=7` `--prewarm` `--set=portrait|square|landscape` `--hour=18.5`(그 시각에 멈춤) `--time=real|fast` `--vf=0.5,0.45` `--bg_ratio=1.0` `--smooth=0` `--snap=1` `--panel` `--dex` `--detail=<종ID>` `--found=<종ID,...>` `--save=user://파일.json` `--fresh` `--shoot` `--selftest` `--capture=파일.png`

## 하는 법

- 화면 비율에 가장 가까운 배경 벌(세로형·정사각형·가로형)이 화면에 꽉 차게 보인다. 화면은 고정이고, 폴더블을 접고 펴거나 태블릿을 돌리면 벌을 다시 고른다.
- 새는 실제 탐조하듯 한 화면에 0~2마리다. 아무도 없으면 평균 10초 뒤 한 마리가 오고, 8~24초 앉아 있다 떠난다. 두 번째 새는 드물게 온다(보이는 시간 비율: 없음 약 31%, 한 마리 63%, 두 마리 5%). 이 값은 설정으로 바꾸지 않는다.
- 새는 화면에 보이는 횃대(가지, 가로등, 벤치, 갈대, 물, 길, 풀밭)에 내려앉았다가 떠난다. 어떤 새가 언제 오는지는 화면과 상관없이 정해서 기기마다 확률이 같다.
- 배경과 새 빛깔은 시간대(새벽 5:45, 낮 7~17시, 해 질 녘 18:30, 밤 20~4:30)를 따른다. 기본은 5분에 하루가 지나고, 기기 시계의 지금 시각에서 시작한다.
- 네 귀퉁이 괄호가 뷰파인더다. 빈 곳을 누르면 그 자리로 오고, 누른 채 끌면 따라온다. 새 그림의 70% 이상이 괄호 안일 때 셔터를 누르면 찍힌다(나는 새도 된다).
- '도감'에서 찾은 새를 누르면 자세히 볼 수 있다. 기록은 기기 안 `user://save.json`에 남는다(날짜와 횟수만, 위치 없음).
- 안드로이드 뒤로 가기는 열린 창부터 닫고, 아무것도 없으면 앱을 끝낸다.

## 시험판에서 볼 것

- 저가 폰에서도 60fps를 유지하는지(왼쪽 위 숫자), 10분쯤 두었을 때 뜨거워지지 않는지
- 폴더블을 접고 펴거나 화면을 돌려도 그림이 깨지지 않는지, 벌이 바뀔 때(왼쪽 위 숫자 옆에 벌 이름이 뜬다) 어색하지 않은지
- 새를 찾아 찍는 게 몇 분 동안 재미있는지 (0단계의 핵심 질문)
- 새 수와 오는 간격이 실제 탐조하는 느낌인지
- 시간: '5분에 하루'와 '실제 시간' 중 어느 쪽이 나은지 ('설정'에서 바꿔 본다. 정하면 이 설정은 뺀다)
- '설정'에서: 배경 칸 1.0배와 1.25배, 칸 경계 섞기 켬·끔, 칸 단위로 움직이기

## 임시인 것

- 그림: 디자인 캔버스 시안에서 뽑았다. 배경은 그려져 있던 새를 지우고 주변 색으로 메워서 다리와 가로등 머리에 흔적이 조금 남았다.
- 배경 세 벌: 시안 월드 하나에서 잘라 만들었다. 비율이 조금 다른 기기에서 나무 줄기가 잘리지 않게 왼쪽을 이어 붙여서 줄기가 굵어 보이고, 가로형은 나무 윗부분이 잘린다. 디자인 세션이 세 벌을 따로 그리면 바꾼다.
- 날개 그림: 까치와 참새만 한 장씩 있다. 나머지 새는 날 때도 기본 자세(살짝 눌렀다 폈다)를 쓴다.
- 저녁·새벽·밤 색표: 코드 세션이 낮 색에서 만든 임시 변환이다. 새도 시간대에 따라 조금 물들이는데 이것도 임시다.
- 횃대 좌표: 시안 장면에서 새가 앉아 있던 자리를 보고 잡았다.
- 글꼴: 갈무리11 부분 글꼴(OFL).
- 패키지 이름 `dev.nearwings.proto`와 디버그 서명 키(`tools/keys/`)는 시험용이다. 공개 전에 바꾼다.
